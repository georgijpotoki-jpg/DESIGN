## 1. Огляд проєкту
**Мета:** Розробка консольного додатка (CLI) для інтерактивної текстової гри (або каталогу персонажів) з можливістю керування ігровим процесом, вибору персонажів та збереження прогресу.
**Технологічний стек:** Python 3.10+ (стандартні бібліотеки `json`, `os`, `sys`).
**Архітектурний підхід:** Розділення логіки інтерфейсу (CLI) та бізнес-логіки / роботи з даними (на даному етапі реалізовано через заглушки/стаби).

## 2. Структура додатка (Архітектура)

Проєкт має модульну структуру для легкого масштабування на наступних етапах розробки:

```text
project-root/
│
├── main.py              # Точка входу в програму, запуск головного циклу CLI
├── cli.py               # Модуль консольного інтерфейсу (меню, обробка вводу користувача)
├── game_engine.py       # Бізнес-логіка гри (зараз містить стаби/заглушки)
├── storage.py           # Модуль збереження та завантаження даних (JSON)
├── data/
│   └── save_data.json   # Файл для збереження прогресу користувача
├── DESIGN.md            # Дизайн-документ проєкту
└── README.md            # Інструкція із запуску
```

### Опис модулів:
* **`main.py`** — ініціалізує необхідні компоненти та передає керування в `cli.py`.
* **`cli.py`** — відповідає виключно за взаємодію з користувачем через термінал (виведення тексту, валідація команд, навігація по меню).
* **`game_engine.py`** — містить класи та функції для обробки ігрових подій (стаби, що повертають тестові сценарії, характеристики персонажів та результати дій).
* **`storage.py`** — забезпечує серіалізацію та десеріалізацію стану гри у формат JSON.

## 3. Детальний опис реалізації консольного інтерфейсу (CLI)

Консольний інтерфейс побудований за принципом **скінченного автомата (State Machine)** з використанням циклів `while` та обробки винятків для захисту від некоректного вводу користувача.

### 3.1. Головне меню
При запуску програми користувач бачить головне меню з нумерованим списком дій:
1. `Почати нову гру` — перехід до екрана вибору персонажа.
2. `Завантажити збережену гру` — зчитування останнього стану з файлу `save_data.json` та відновлення ігрового циклу.
3. `Переглянути статистику / результати` — виведення таблиці попередніх проходжень.
0. `Вихід` — коректне завершення роботи програми.

### 3.2. Екран вибору персонажа
* CLI запитує список доступних персонажів із `game_engine.py`.
* На екран виводиться ім'я, клас та короткий опис кожного героя.
* Користувач вводить номер персонажа. Програма перевіряє, чи входить число в діапазон доступних індексів.

### 3.3. Основний ігровий цикл (Game Loop)
Після вибору персонажа запускається цикл гри, який триває до перемоги, поразки або ручного виходу в меню:
1. **Виведення стану:** Відображається поточна локація, здоров'я (HP), рівень та опис ситуації (отримується зі стабу).
2. **Доступні дії:** Користувачу пропонується набір команд:
   * `[1] Дослідити локацію`
   * `[2] Атакувати / Взаємодіяти`
   * `[3] Зберегти прогрес`
   * `[0] Завершити гру (повернутися в головне меню)`
3. **Обробка вибору:** Введена команда передається в `game_engine.py`, який повертає текстовий результат дії та оновлені характеристики.

### 3.4. Збереження стану та результатів
* При виборі опції збереження викликається метод `save_state()`, який записує поточний словник стану (ім'я персонажа, HP, поточний крок, інвентар) у `data/save_data.json`.
* Після завершення гри фінальний рахунок додається до історії результатів.
